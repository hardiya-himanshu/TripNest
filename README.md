# TRIPNEST 

### TripNest is a web-tech solution for hassle-free booking of your next tour. TripNest offers large variety of tours/packages, top-destinations, destinations categorized by continents, hotels for accomodations and special discounts.

## Steps:

- First download the zip file/clone the project.

- Open in VSCode => Open **backend** folder in Integrated Terminal and run **npm i**.

- Then run **npm i axios bcrypt buffer cloudinary cors dotenv express jsonwebtoken mongoose nodemailer nodemon razorpay**.

- create **.env** extension file in backend and then copy the content from sample.env and modify it as per yours.

- Now in **frontend** folder, similiarly open it in Integrated Terminal and run **npm i**.

- Then run **npm i @fortawesome/react-fontawesome @googlemaps/js-api-loader @googlemaps/react-wrapper @react-google-maps/api axios buffer cloudinary gsap multer nanoid react react-anchor-link-smooth-scroll react-audio-player react-dom react-router-dom react-scroll react-toastify sonner use-local-storage**.

### Now you are ready to open TripNest in browser for that you need to follow three steps:
  
- Open **backend** folder in Integrated Terminal and run **npm start**.

- Then open **frontend** folder in Integrated Terminal, run **npm run dev** then open localhost link.

- Lastly open your own MongoDB Compass or MongoDB Atlas in browser to access an observe changes in database.
